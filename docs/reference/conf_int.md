# Calculate confidence intervals

Calculates confidence intervals for each distribution-estimation result
in \`df\`. Normal, Lognormal, and Nonparametric distributions are
dispatched to the corresponding EnvStats estimation function. Censored
Normal and Lognormal data are dispatched to the corresponding
censored-data method when \`censored_col\` identifies censored
observations.

## Usage

``` r
conf_int(
  df,
  method = "mvue",
  ci_type = "lower",
  ci_param = "mean",
  conf_level = 0.95,
  analysis_result = ".analysis_result",
  censored_col = NULL,
  censored_args = list(censoring.side = "left"),
  nonparametric_args = list(p = 0.5, type = 7, lcl.rank = NULL, ucl.rank = NULL, lb =
    -Inf, ub = Inf, ci.method = "interpolate", min.coverage = TRUE, tol = 0)
)
```

## Arguments

- df:

  A data frame returned by \[est_dist()\] with \`keep_data_object =
  TRUE\`.

- method:

  Character string specifying the estimation method passed to EnvStats.

- ci_type:

  Character string specifying the confidence-interval type. Supported
  values are \`"two-sided"\`, \`"upper"\`, and \`"lower"\`.

- ci_param:

  Character string specifying the parameter for which the interval is
  calculated, such as \`"mean"\`, \`"median"\`, \`"quantile"\`, or
  \`"geometric.mean"\`, depending on the selected EnvStats function.

- conf_level:

  A scalar between 0 and 1 specifying the confidence level.

- analysis_result:

  Character scalar giving the name of the result column inside each
  nested data frame.

- censored_col:

  Optional character scalar giving the name of a logical
  censoring-indicator column inside each nested data frame. \`TRUE\`
  identifies a censored observation.

- censored_args:

  Named list of additional arguments passed to the censored EnvStats
  function. For left-censored groundwater data, use
  \`list(censoring.side = "left")\`.

- nonparametric_args:

  Named list of additional arguments passed to \[EnvStats::eqnpar()\].

## Value

A data frame containing the grouping columns from \`df\`, the estimated
distribution, sample size, confidence level, and confidence limits:

- \`lcl\`: lower confidence limit;

- \`ucl\`: upper confidence limit;

- \`sample_size\`: number of observations used;

- \`conf_level\`: confidence level.

## Details

The input must be generated by \[est_dist()\] with \`keep_data_object =
TRUE\`.

## See also

\[est_dist()\], \[tol_int()\], \[EnvStats::enorm()\],
\[EnvStats::elnorm()\], \[EnvStats::eqnpar()\]
