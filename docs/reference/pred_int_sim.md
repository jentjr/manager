# Calculate simultaneous prediction intervals

Calculates simultaneous prediction intervals for each
distribution-estimation result in \`df\`. The calculation is delegated
to the corresponding EnvStats simultaneous prediction-interval function.

## Usage

``` r
pred_int_sim(
  df,
  n_mean = 1,
  k = 1,
  m = 2,
  r = 1,
  rule = "k.of.m",
  pi_type = "upper",
  conf_level = 0.95
)
```

## Arguments

- df:

  A data frame returned by \[est_dist()\] with \`keep_data_object =
  TRUE\`.

- n_mean:

  Positive integer specifying the number of observations used to
  calculate each future mean or geometric mean.

- k:

  Positive integer specifying the number of future observations or means
  in each future set.

- m:

  Positive integer specifying the number of future sets.

- r:

  Positive integer specifying the number of future sets that must be
  covered when using an \`r.of.m\` coverage rule.

- rule:

  Character string specifying the simultaneous-coverage rule accepted by
  EnvStats, such as \`"all.of.m"\` or \`"r.of.m"\`.

- pi_type:

  Character string specifying the interval type. Supported values are
  \`"two-sided"\`, \`"upper"\`, and \`"lower"\`.

- conf_level:

  A scalar between 0 and 1 specifying the confidence level.

## Value

A data frame containing the grouping columns from \`df\`, the estimated
distribution, sample size, confidence level, and simultaneous prediction
limits.

## Details

The input must be generated by \[est_dist()\] with \`keep_data_object =
TRUE\`.

## See also

\[pred_int()\], \[est_dist()\], \[EnvStats::predIntNormSimultaneous()\],
\[EnvStats::predIntLnormSimultaneous()\],
\[EnvStats::predIntNparSimultaneous()\]
