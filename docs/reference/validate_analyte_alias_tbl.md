# Validate analyte alias table

Validates the structure and integrity of an analyte alias table.

## Usage

``` r
validate_analyte_alias_tbl(alias_tbl, analyte_tbl)
```

## Arguments

- alias_tbl:

  Analyte alias table.

- analyte_tbl:

  Canonical analyte metadata table.

## Value

Invisibly returns \`TRUE\`.
