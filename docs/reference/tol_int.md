# Calculate tolerance intervals

Calculates tolerance intervals for each distribution-estimation result
in \`df\`. Uncensored observations are dispatched to the corresponding
EnvStats tolerance-interval function. When \`censored_col\` is supplied
and contains censored observations, the appropriate censored EnvStats
function is used when available.

## Usage

``` r
tol_int(
  df,
  analysis_result = "analysis_result",
  distribution = "distribution",
  censored_col = NULL,
  coverage = 0.95,
  cov_type = "content",
  ti_type = "two-sided",
  method = "exact",
  conf_level = 0.95,
  censoring_side = "left"
)
```

## Arguments

- df:

  A data frame returned by \[est_dist()\] with \`keep_data_object =
  TRUE\`.

- analysis_result:

  Character scalar giving the name of the result column inside each
  nested data frame.

- distribution:

  Character scalar giving the name of the distribution column in \`df\`.

- censored_col:

  Optional character scalar giving the name of a logical
  censoring-indicator column inside each nested data frame. \`TRUE\`
  identifies a censored observation.

- coverage:

  A scalar between 0 and 1 specifying the desired population coverage.
  For \`cov_type = "expectation"\`, EnvStats may ignore this argument.

- cov_type:

  Coverage type. Supported values are \`"content"\` and
  \`"expectation"\`.

- ti_type:

  Tolerance-interval type. Supported values are \`"two-sided"\`,
  \`"upper"\`, and \`"lower"\`.

- method:

  Character string specifying the method used for parametric tolerance
  intervals.

- conf_level:

  A scalar between 0 and 1 specifying the confidence level of the
  tolerance interval.

- censoring_side:

  Character string specifying the censoring direction passed to
  EnvStats. Use \`"left"\` for typical groundwater nondetect data.

## Value

A data frame containing the grouping columns from \`df\`, the estimated
distribution, sample size, confidence level, and tolerance limits:

- \`ltl\`: lower tolerance limit;

- \`utl\`: upper tolerance limit;

- \`sample_size\`: number of observations used;

- \`conf_level\`: confidence level.

## Details

The input must be generated by \[est_dist()\] with \`keep_data_object =
TRUE\`.

## See also

\[est_dist()\], \[conf_int()\], \[EnvStats::tolIntNorm()\],
\[EnvStats::tolIntLnorm()\], \[EnvStats::tolIntNpar()\],
\[EnvStats::tolIntNormCensored()\]
