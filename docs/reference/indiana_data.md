# Groundwater quality data for the state of Indiana

A dataset containing groundwater quality data for the state of Indiana.

## Usage

``` r
indiana_data
```

## Format

A data frame with 162923 rows and 11 variables:

- SiteID:

  Site Identifier

- Result:

  analytical result

- Analyte:

- DetectionLimit:

- Method:

- SampleDate:

- SampleID:

- UTM_X:

- UTM_Y:

- Unit:

- WellDepth:
