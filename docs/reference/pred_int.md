# Calculate prediction intervals

Calculates prediction intervals for each distribution-estimation result
in \`df\`. Normal, Lognormal, and Nonparametric distributions are
dispatched to the corresponding EnvStats prediction-interval function.

## Usage

``` r
pred_int(
  df,
  method = "Bonferroni",
  n_mean = 1,
  k = 1,
  pi_type = "upper",
  conf_level = 0.95
)
```

## Arguments

- df:

  A data frame returned by \[est_dist()\] with \`keep_data_object =
  TRUE\`.

- method:

  Character string specifying the method used to calculate a parametric
  prediction interval. The value is passed to
  \[EnvStats::predIntNorm()\] or \[EnvStats::predIntLnorm()\].

- n_mean:

  Positive integer specifying the number of observations used to
  calculate each future mean or geometric mean. The default, \`1\`,
  calculates an interval for individual future observations.

- k:

  Positive integer specifying the number of future observations or means
  the interval should contain.

- pi_type:

  Character string specifying the interval type. Supported values are
  \`"two-sided"\`, \`"upper"\`, and \`"lower"\`.

- conf_level:

  A scalar between 0 and 1 specifying the confidence level.

## Value

A data frame containing the grouping columns from \`df\`, the estimated
distribution, sample size, confidence level, and prediction limits:

- \`lpl\`: lower prediction limit;

- \`upl\`: upper prediction limit;

- \`sample_size\`: number of observations used;

- \`conf_level\`: confidence level.

## Details

The input must be generated by \[est_dist()\] with \`keep_data_object =
TRUE\`.

## See also

\[pred_int_sim()\], \[est_dist()\], \[EnvStats::predIntNorm()\],
\[EnvStats::predIntLnorm()\], \[EnvStats::predIntNpar()\]

## Examples

``` r
# \donttest{
data("gw_data")

wells <- c("MW-1", "MW-2", "MW-3", "MW-4")
params <- c(
  "Sulfate, total",
  "Arsenic, dissolved",
  "Boron, dissolved"
)

background <- lubridate::ymd(
  c("2007-12-20", "2012-01-01"),
  tz = "UTC"
)

background_data <- gw_data |>
  dplyr::filter(
    location_id %in% wells,
    param_name %in% params,
    sample_date >= background[1],
    sample_date <= background[2]
  ) |>
  dplyr::group_by(
    location_id,
    param_name,
    default_unit
  ) |>
  percent_lt() |>
  est_dist(keep_data_object = TRUE)
```
