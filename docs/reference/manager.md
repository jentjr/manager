# Function to launch shiny app for MANAGER

Provides tools for managing, analyzing, and visualizing environmental
monitoring data. Includes a schema-based data model for standardized
environmental datasets, statistical summaries, trend analysis,
censored-data methods, prediction and tolerance intervals, groundwater
monitoring workflows, and hydrochemical visualizations including Piper,
Durov, Schoeller, and Stiff diagrams. Supports integration with external
environmental data sources such as MANAGES.

## Usage

``` r
manager()
```
