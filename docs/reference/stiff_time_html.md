# Save animated Stiff Diagram to HTML

Save animated Stiff Diagram to HTML

## Usage

``` r
stiff_time_html(df, htmlfile = "Stiff_plot.html", pause = 1, ...)
```

## Arguments

- df:

  Data frame of water quality data.

- htmlfile:

  Output HTML file.

- pause:

  Delay between frames in seconds.

- ...:

  Additional arguments passed to \`stiff_plot()\`.

- sample_date:

  Sample date column.

## Value

Invisibly returns htmlfile.
