Introduction

The plotting module provides a unified suite of visualization functions for environmental monitoring datasets.

All plotting functions support both raw data frames and env_schema objects through S3 method dispatch. The system is designed to operate independently of source column names by relying on schema mappings and accessor functions.

Supported visualizations include:

  • Time-series plots
  • Boxplots
  • Correlation plots
  • Piper diagrams
  • Schoeller diagrams
  • Stiff diagrams
  • Durov diagrams
  • Spatial plots
  • Geochemical animations

Design Philosophy

Schema-Aware Architecture

All environmental plotting functions ultimately operate on an env_schema object.

When a raw data frame is supplied, it is first converted using user-provided column mappings.

For example:

series_plot(
  groundwater_data,
  location = well_id,
  sample_date = sample_date,
  analyte = constituent,
  result = concentration
)

internally becomes:

env_schema(
  groundwater_data,
  location = well_id,
  sample_date = sample_date,
  analyte = constituent,
  result = concentration
)

Internally, plotting methods interact with schema accessors rather than hard-coded column names:

location_var()
sample_date_var()
analyte_var()
analysis_result_var()
analysis_unit_var()
reporting_flag_var()

This architecture ensures plots remain portable across different environmental datasets.

  result = analysis_result,
  unit = default_unit,

Extending the Plotting Framework

New visualization functions should follow the same S3 design pattern used throughout the package.

data.frame Method

my_plot.data.frame <- function(
  df,
  location,
  sample_date,
  analyte,
  result,
  ...
) {

  df <- env_schema(
    df,
    location = {{ location }},
    sample_date = {{ sample_date }},
    analyte = {{ analyte }},
    result = {{ result }}
  )

  my_plot(df, ...)
}

env_schema Method

my_plot.env_schema <- function(
  df,
  ...
) {

  location_col <- location_var(df)

  sample_date_col <- sample_date_var(df)

  analyte_col <- analyte_var(df)

  result_col <- result_var(df)

  ...
}

Following this pattern ensures all future visualizations remain independent of source column names while remaining fully compatible with the package schema system.

Summary

The environmental plotting framework provides:

  • Schema-aware plotting
  • Support for raw data frames and env_schema objects
  • Consistent handling of analytical metadata
  • Hydrochemical interpretation tools
  • Animation support
  • Extensible S3-based architecture

By leveraging schema accessors rather than hard-coded field names, plots remain portable, reusable, and robust across diverse environmental datasets.
